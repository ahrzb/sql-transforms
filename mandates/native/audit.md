# Native catalog: audit log

## 2026-10-17 granted-from-the-loop

The maintainer asked, in the session of 2026-10-17, to turn the native-transform loop into a mandate. This entry records the choices made in translating the loop's rules; each restates an existing rule unless it says otherwise.

- **Kind:** mission, because the loop's goal ended when every in-scope class is native. Alternative: a standing mandate tending coverage; rejected because the goal has a completion condition.
- **Status:** running, because no pause of this loop was recorded. The confit loop's pause was.
- **Folder name:** `native`, the loop's name, so that the `loop:` key of the reports still names the folder the maintainer's tracker reads. Alternative: `native-catalog`; rejected for that reason.
- **Limits:** 4 claimed tasks, from the old rule of at most 4 open pull requests waiting for review. Working several at once is held by [may a delegate run several tasks at once](../../questions/open/parallel-tasks-under-a-mandate.md).
- **Boundary:** the loop's rules became permissions with exceptions: the twin is the reference; a bound above 0 or a widening needs a closed proposal (the old closed decision records are now [closed proposals](../../proposals/README.md)); the loop never changed `packages/confit/`; contract and scope changes went to the maintainer; shared machinery needed the ticket to say so first. The old cost-notice edit of the other loop's plans became "add needs to the tracker of confit".
- **Independent review:** only what `AGENTS.md` requires, which is what the loop required: supervisor review of worker pull requests, which `repo-docs` does not count as independent. The maintainer is structuring review himself.
- **Reporting contract:** the old triggers and KPI block, kept exactly, because the tracker reads the keys. The old report shape became added detail under the `repo-docs` report sections.
- **Files:** `PLANS.md` and `tickets.md` became the tracker and task descriptions; `worker-brief.md`, the cycle, the review checklist and `traps.md` became the brief; `goal.md` became the objective; the shared `loops/` rules went to `AGENTS.md`, the brief or this README. The cross-loop needs registry became the confit tracker's **Needs**.

Reopens when the maintainer changes any of these.
