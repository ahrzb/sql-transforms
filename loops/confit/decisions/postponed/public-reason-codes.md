# Stable public refusal codes

**Question.** Should refusals carry stable, machine-readable public codes?

**Ruling.** Not now. Audit classifications stay internal; public diagnostics name
the unsupported construct and say what to do ([oracle policy](../closed/oracle-policy.md#reporting-and-measurement)).

**Reopens when** a concrete consumer needs to branch on refusal kind; the codes
then need their own API decision (naming, stability, versioning).
